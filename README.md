# Second Hand Marketplace

## Giới thiệu
Website mua bán đồ second-hand, hỗ trợ người dùng đăng bán, tìm kiếm sản phẩm và đặt hàng.

## Công nghệ sử dụng
- Backend: ASP.NET Core MVC, C# (.NET 10)
- Frontend: Razor Views, HTML, CSS, JavaScript, Bootstrap 5
- Database: SQL Server
- ORM: Entity Framework Core
- Version control: Git và GitHub

## Quy trình làm việc
- `main`: phiên bản ổn định.
- `dev`: nhánh tích hợp code của nhóm.
- `feature/*`: nhánh phát triển chức năng.
- `fix/*`: nhánh sửa lỗi.

## Hướng dẫn chạy dự án
Sẽ được cập nhật sau khi nhóm hoàn thiện bộ khung project.
